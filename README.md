# TSCM Field Operator App: download

Android app for TSCM (technical surveillance countermeasures) sweeps.

## Download the newest version

https://github.com/jmlasorsa/tscm-field-releases/releases/latest/download/tscm-field.apk

1. Open that link on the Android phone. No GitHub account is needed.
2. Open the downloaded file and allow the install when Android asks.
3. After that, the app updates itself: it checks this page each time it opens and installs new versions with one tap.

This page holds only the app file. The source code is private.
